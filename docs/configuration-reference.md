# Configuration

This is not a public library. There is no published Node client options object.

The product is the [CLI](../README.md). Runtime knobs are environment variables (`ALUVIA_API_KEY`, `ALUVIA_HOME`, `ALUVIA_API_BASE_URL`, `ALUVIA_UPSTREAM`, `ALUVIA_GATEWAY_HOST`, `ALUVIA_GATEWAY_PORT`) and `aluvia` commands (`auth`, `proxy-provider`, `setup`).
